Integration Flow

从 API Key 到模型路由

Pigcoder 的页面信息围绕开发者接入路径组织：创建密钥、选择协议、替换 Endpoint、观察请求日志。

01

创建 API Key

在控制台创建令牌，并按工具选择 OpenAI、Anthropic 或 Gemini 分组。

02

选择协议

根据 Claude Code、Codex CLI、Gemini CLI 等工具选择对应协议入口。

03

替换 Endpoint

只改 Base URL 和 API Key，尽量保持原工具配置方式不变。

04

查看日志

通过请求日志追踪模型、渠道、用量、状态和异常原因。
