Studio 使用

进入 Studio

访问 pigcode.ai/connect/studio，使用与控制台相同的账号登录即可，无需任何配置。对话、图片与视频创作和 API 共用同一份余额，消费明细可在控制台「日志」中查看。

对话

  • 顶部选择分组与模型——分组对应价格页的渠道倍率，模型来自该分组的可用列表。
  • 回复为流式输出，支持推理过程（reasoning）展示与消息级操作（重试、复制等）。
  • 聊天记录保存在浏览器本地（localStorage），按浏览器隔离——换设备或清缓存不会同步，重要内容请自行留存。

图片生成

进入创作台（Studio 页内「创作」入口），计费 $0.2 / 张：

  • GPT Image 2——文生图、以图生图与编辑链，支持多张参考图连续编辑。
  • Grok Imagine 系列——文生图（暂不支持尺寸/质量参数，画幅用提示词约束）。
  • 生成记录保存在浏览器本地（IndexedDB），支持批量下载与删除；刷新页面任务自动恢复。

视频生成

当前提供 Grok Imagine 视频（更多视频模型陆续接入），支持文生视频与图生视频，时长可选 5 / 10 / 15 秒，计费 $0.05 / 秒（约 $0.25–$0.75 一条）：

  • 视频为异步生成，创建任务后可离开页面，回来自动恢复进度。
  • 图生视频：上传一张图作为首帧，配合提示词控制运动方向。

注意：生成完成的视频链接约 2 小时后过期，请及时下载保存。

语音生成

文本转语音，当前可用 grok-voice-think-fast-2.0，计费 $0.02 / 千字符（一段 500 字口播约 $0.01）。输入文本、选择模型，生成后可在线播放与下载。

gpt-realtime-2.1 与 suno-v5（音乐生成）正在接入中，上线后会直接出现在模型选择器里。

灵感墙

Studio 内置公开案例库「灵感墙」：浏览各类风格的生成案例，看到喜欢的效果，一键把 Prompt 带入创作台，在此基础上改出自己的版本。

实战教程

Vibe coding：把 Claude Code 接上 Pigcode

目标与成本

目标：十分钟内把 Claude Code 切到 Pigcode 端点，并让它写出一个能跑的命令行小工具。

成本参考：对话按所选模型 token 计价，注册赠送的 $1 体验额度足够跑完全篇。

前置

  1. 已注册 Pigcode 控制台账号（注册即送 $1 体验额度）。
  2. 本机装有 Node.js v18+。

步骤

  1. 安装 Claude Code：npm install -g @anthropic-ai/claude-code。
  2. 控制台左侧「令牌」→「创建令牌」，复制生成的 sk-pig- 开头密钥（只显示一次）。
  3. 终端里设两个环境变量：export ANTHROPIC_BASE_URL="https://pigcode.ai" 与 export ANTHROPIC_API_KEY="sk-pig-xxxx"。
  4. 新建一个空目录并进入，运行 claude，用 /model 确认切到 claude-fable-5。
  5. 下第一个任务：「写一个命令行小工具 csv2md：读入 CSV 文件，输出 Markdown 表格，附一份 README」。
  6. 让它自证：「造一个 3 行的测试 CSV，跑一遍，输出不对就修到对」。
  7. 收尾用 /cost 看本次消耗，控制台「日志」里能对上每笔明细。

模型怎么选

Claude Code 里默认 claude-fable-5，改代码与长会话最稳。想换工具链：Codex CLI 配 gpt-5.6-sol（OPENAI_BASE_URL=https://pigcode.ai/v1），Gemini CLI 配 gemini-3.7-flash（GOOGLE_GEMINI_BASE_URL=https://pigcode.ai/v1beta）。同一把钥匙、同一份余额，三条线随时切。

常见问题

问：请求报 401 或超时？答：先检查端点是否误加了 /v1——Claude Code 走 Anthropic 协议，只用 https://pigcode.ai；再确认密钥完整、以 sk-pig- 开头。

写文案：把一条推文从选题磨到成稿

目标与成本

目标：在 Studio 对话里，从 3 个选题角度出发，把一条产品推文从初稿磨到能直接发。

成本参考：对话按所选模型 token 计价，几轮打磨只花掉 $1 体验额度的零头。

前置

  1. 用控制台账号登录 https://pigcode.ai/connect/studio（注册即送 $1 体验额度）。
  2. 准备一句话产品介绍和目标读者画像。

步骤

  1. 打开 Studio 对话，顶部模型选 claude-fable-5。
  2. 喂背景要选题：「产品是给独立开发者的周报生成器，读者是 indie hacker，给 3 个推文选题角度，各配一句开头钩子」。
  3. 选定角度出初稿：「用第 2 个角度写一条 100 字以内的推文，短句，别用感叹号」。
  4. 做减法：「删掉所有形容词，再压掉 20% 字数，信息一条不能丢」。
  5. 换结尾：「给 3 个不同的行动号召结尾，各一句」。
  6. 让它挑刺：「站在刷到这条推文的人的角度，说说你为什么不会点开」。
  7. 按挑刺意见改出最后一版，通读一遍，把不像你口吻的词换掉。

模型怎么选

中文推文默认 claude-fable-5，多轮改写里语气拿得最稳。要一口气铺 10 版备选，切 gemini-3.7-flash，速度快。英文稿可以让 gpt-5.6-sol 平行写一版对照。

常见问题

问：换了台电脑，昨天的对话不见了？答：Studio 聊天记录保存在浏览器本地，不跨设备同步，定稿请当场复制留存。

画海报：编辑链迭代一张活动海报

目标与成本

目标：用 gpt-image-2 从一句提示词起步，经编辑链三轮小步迭代，拿到一张能直接发的活动海报。

成本参考：图像 $0.2 / 张，本篇约生成 5 张，合计约 $1。

前置

  1. 用控制台账号登录 https://pigcode.ai/connect/studio，进入创作台的图像模式。
  2. 余额不低于 $1（充值支付宝/微信 5 元起，¥1 = $1 入账）。

步骤

  1. 模型选 gpt-image-2，写首版提示词：「周末咖啡市集海报，奶油底色，扁平插画，竖版构图，大标题『City Roast』，留白多一点」。
  2. 生成 2 张候选，挑构图与文字更稳的一张进入编辑链。
  3. 编辑第一轮只改一件事：「底色换成深绿色，其余全部保持不变」。
  4. 第二轮补信息：「标题下方加一行小字『8.23–8.24 · 滨江仓库』，层级低于标题」。
  5. 第三轮收细节：「右下角加一枚极小的咖啡杯图标，整体构图不动」。
  6. 逐版对比，回生成记录把定稿原图下载保存。

模型怎么选

要连续编辑就用 gpt-image-2——文生图、以图生图、编辑链都支持，做海报的默认答案。想对比另一种风格，同一提示词抽一版 grok-imagine-image-2.0（画幅用提示词约束）或 gemini-3-pro-image，但改图仍回到 gpt-image-2 里做。

常见问题

问：只想改一处，结果整张图都变了？答：一次只提一个改动，并在指令里写明「其余保持不变」；改崩了就回上一版重新编辑，每一步的生成记录都还在。

出视频：把海报变成 10 秒宣传片

目标与成本

目标：把一张海报设为首帧，用 grok-imagine-video-1.5 生成一条 10 秒 720p 的动态宣传片。

成本参考：视频 $0.05 / 秒，10 秒一条 $0.5，预留一次重生成共约 $1。

前置

  1. 一张海报图（上一篇的产出即可）。
  2. 登录 Studio 创作台切到视频模式，余额不低于 $1。

步骤

  1. 模型选 grok-imagine-video-1.5，上传海报作为首帧。
  2. 写运动提示词：「镜头缓慢推近标题，杯口蒸汽升起，光线从左上角扫过，节奏平缓，文字保持清晰」。
  3. 时长选 10 秒，分辨率选 720p（也可先花 $0.25 用 5 秒 480p 试运动方向）。
  4. 提交任务；视频为异步生成，可离开页面，回来自动恢复进度。
  5. 预览成片，运动跑偏就把幅度写小（如「轻微推近」）再生成一次。
  6. 定稿后下载 mp4，生成结果默认同时存入账号云端历史。

模型怎么选

视频当前只有 grok-imagine-video-1.5 系列，不用纠结。省预算的路线是先 5 秒 480p 验证运动方向，对了再上 10 秒 720p 出正片。更多视频模型陆续接入中。

常见问题

问：海报上的文字一动就糊？答：首帧文字要大而少，提示词写明「文字保持清晰、镜头轻微移动」，并选 720p；文字密集的海报只做轻推近。

配人声：给宣传片配一段口播旁白

目标与成本

目标：给 10 秒宣传片写一段旁白，用 grok-voice-think-fast-2.0 合成人声，在本地把音画合并导出成片。

成本参考：语音 $0.02 / 千字符，一段 10 秒旁白约 60 字，试上三版也不到 $0.01。

前置

  1. 一条已下载的视频（上一篇的 10 秒宣传片即可）。
  2. 本机装有 ffmpeg（或任一剪辑软件）用于合并音画。

步骤

  1. 先写稿：10 秒约容纳 50–70 个中文字，按「一句钩子＋一句信息＋一句行动」写，如「这个周末，来 City Roast 咖啡市集：8 月 23 到 24 日，滨江仓库，三十家摊主到齐。」
  2. 在 Studio 导航打开「语音」页，粘贴文稿，模型选 grok-voice-think-fast-2.0。
  3. 点生成，在线试听整段。
  4. 节奏不对就改标点重生成：多用句号增加停顿，长句拆短。
  5. 满意后下载音频文件，与视频放进同一目录。
  6. 一条命令合并：ffmpeg -i promo.mp4 -i voice.mp3 -map 0:v -map 1:a -c:v copy -shortest final.mp4。
  7. 播放 final.mp4 检查：旁白比画面略短最自然，超长就回第 4 步删字。

模型怎么选

语音当前可用 grok-voice-think-fast-2.0，中英文稿都直接用它。实时通话（gpt-realtime-2.1）与音乐生成（suno-v5）正在接入中，上线后会直接出现在模型选择器里。

常见问题

问：能顺便加背景音乐吗？答：音乐生成（suno-v5）正在接入中，目前请用本地音乐素材，在 ffmpeg 或剪辑软件里与旁白混音。
