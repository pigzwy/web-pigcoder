## 一、一句话定位

> **一把钥匙，用遍全球模型。**
> One key opens every model.

「钥匙」是整个品牌的核心隐喻：它既是字面的 API Key，也是打开全球模型能力的那把金钥匙（品牌金 `#E8A825`）。一个账户、一份余额、一把钥匙，通向五件事：**敲代码、写文案、画海报、出视频、配人声**。

## 二、故事支柱（对外表达的四根柱子）

| 支柱 | 说法 | 落点 |
|---|---|---|
| 一把钥匙 | 一个账户一份余额，API 与 Studio 通用 | 首页 hero、价格页 |
| 五种能力 | 动词化表达：敲代码/写文案/画海报/出视频/配人声 | 首页五业务区 |
| 透明计价 | 图 ¥0.2/张、视频 ¥0.05/秒、对话按 token、倍率公开 | 价格页创作计价 + 倍率表 |
| 不锁平台 | 三协议兼容、换 Base URL 就走、模型目录开放 | 文档页、模型目录 |

语言风格：动词优先、数字说话、不用形容词堆砌；中文态零负字距、等宽数字（见设计规范）。

## 三、现状盘点（2026-08-17，诚实版）

**已兑现：**
- 网关：三协议（OpenAI/Anthropic/Gemini）、sub2api 分组倍率（0.08x–4.5x）、CLI 全家桶接入文档
- 模型目录：5,097 模型 / 60 厂商全量元数据，模态快捷筛选（?m= 直达）
- Studio：流式对话（分组/模型选择、reasoning）、图片生成（GPT Image 2 文生图/以图生图/编辑链、Grok Imagine）、视频生成（Grok Imagine，5/10/15 秒）、灵感墙（案例 Prompt 一键带入）
- 官网：五大业务叙事 + 真实生成素材展示 + 创作计价 + Studio 使用文档

**故事与现实的缺口（按对用户的伤害排序）：**
1. **语音是"故事里有、产品里无"**——首页/文档讲了配人声，Studio 没有音频功能。这是当前最大的诚信缺口。
2. 视频只有 Grok 一家——首页视频卡列了 seedance/veo，Studio 里选不到。
3. Studio 记录只存浏览器本地（localStorage/IndexedDB）——换设备即丢，"工作台"的承诺打折。
4. 灵感墙是外部案例库——没有用户自己的作品沉淀与分享。
5. 视频链接 2 小时过期——体验尾巴。

## 四、路线图

### P0 · 把讲出去的故事补齐（Studio 为主）
- [ ] **Studio 音频上线**：接 `gpt-realtime-2.1` / `grok-voice-think-fast-2.0` / `suno-v5` 任一先跑通 TTS 或音乐生成，定价按秒或按字符，价格页同步
- [ ] **视频模型扩充**：Studio 接入 seedance / veo 系（sub2api 已有渠道即可开）
- [ ] **生成价格展示进 Studio**：生成按钮旁标"¥0.2/张、¥0.05/秒"（前端 shared 层已有价格字段，防展示价与结算价脱钩）
- [ ] 官网跟随：音频上线后把 Audio 卡的"进入 Studio"指到音频入口

### P1 · 让作品留下来、传出去（增长引擎）
- [ ] **生成历史云同步**：账号级历史（后端已有 node:sqlite 账号历史的底子），换设备不丢
- [ ] **作品分享**：单个生成结果一键生成分享页/卡片（带模型名与 Prompt，可选水印）——每个分享都是免费获客
- [ ] **灵感墙 2.0**：用户可发布作品到灵感墙（审核后公开），从"案例库"进化为"社区"
- [ ] 官网 Showcase 页：有一批用户作品后上线（在此之前不做空页面）

### P2 · 商业化加固
- [ ] 充值档位/新手礼金（首充送、注册送体验额度）
- [ ] 用量面板：API + Studio 统一的消费可视化（当前只有日志流水）
- [ ] 团队空间：共享余额、成员管理（服务工作室/小团队客户）

### P3 · 生态与开放
- [ ] 图像/视频/音频的 API 对外开放（当前仅 Studio 内部管线），文档页补 API 参考
- [ ] 灵感墙开放 API / RSS，模型目录数据开放下载（呼应"不锁平台"）
- [ ] 官网 Use cases 页 + 更新日志（有真实素材后）

### 官网侧待办（小事清单）
- [ ] og:image 换成 hero 视频截帧（分享卡片是大片不是 logo）
- [ ] FAQ 补"生成内容版权归属"条目（创作平台高频问题，需先定规则）
- [ ] 高清 hero 视频若再升级（4K 源），重跑压缩管线即可

## 五、成功的度量（建议盯这几个数）

- 故事完整度：五大业务在 Studio 内**全部可用**（feat/omni-p0 合并后 5/5）
- 转化链：首页 → Studio 的点击率；Studio 首次生成完成率
- 留存钩子：作品分享次数（P1 上线后）、灵感墙投稿数
- 商业：充值转化率、图/视频生成量的周环比

## 六、节奏建议

P0 是诚信问题，建议两周内解决（音频哪怕先上一个模型）；P1 是增长飞轮，做完 P0 立刻启动；P2/P3 按用户量触发，不预支。官网已经把故事讲满了——接下来的工作是**让产品追上故事**，而不是继续加故事。
